Identity study · round 01

SOICODER

Three ways to take the original banner further. Same wordmark, same paw, same tricolour bar — treated three different ways so the choice is about where the mark has to survive, not about taste alone.

SOURCE banner artwork, supplied OWNER supasiao7896TH USE dev persona · web app YEAR MARK 2025, retained

The name is the story

Soi — ซอย, the side street. A soi dog and a coder share the same address. The paw is not an ornament bolted onto a wordmark; it is the half of the name that letters cannot spell.

Drawn, not typed

The wordmark is a 5 × 7 bitmap rendered as vector rectangles. No font dependency, no licence to track, and it stays exactly as crisp at 2400 px as it is at 24.

What the round decides

Pick one direction. The next round turns it into the full kit — icon set, clear-space rules, motion, and the app shell it has to live in.

D1

Neon Arcade

→ light README · web app header · social card

The supplied artwork, resolved. Spacing put on the same 8 px grid the letters are drawn on, the bloom rebuilt as a two-pass Gaussian so it survives export, and the paws re-cut so the pads read as pads at any size. This is the safest of the three: nothing about the original is argued with.

D2

CRT Night

→ terminal · dark README · PWA splash

Same lockup, moved to a phosphor screen. Bloom runs hotter, a pink ghost sits one pixel off-register the way a cheap CRT actually misconverges, and a 3 px scanline field holds the whole plate together. This is the direction that matches a terminal-first workflow and the existing dark-mode house style.

D3

Soi Sticker

→ avatar · favicon · PWA icon · merch

Glow is a luxury of large sizes. Below about 64 px it turns a mark into a smudge — so this direction trades it for flat colour, a die-cut keyline and a hard offset shadow, and stacks the wordmark to fit a square. The paw is promoted to lead. It is the only one of the three that is still legible as a 16 px favicon.

These are not mutually exclusive. The usual resolution is one primary plus one utility: D1 or D2 as the primary voice, D3 as the icon system underneath it, since something has to be the 16 px favicon regardless.
