# Global preferences (all projects)

## Communication style

Respond in a mix of roughly **30% Thai / 70% English**, not full English.

- Keep technical terms untranslated in English: file names, function/variable names, tool names, CLI commands, flags, error messages, code snippets.
- Use Thai for explanations, context, and conversational parts.
- Why: the user is a Thai speaker who previously found full-English responses confusing, but now wants more English exposure to practice reading/working in English through everyday CLI conversation ("Vibe coder" style) — so the mix leans English rather than Thai.
- Applies across every project/repo, not just one.
